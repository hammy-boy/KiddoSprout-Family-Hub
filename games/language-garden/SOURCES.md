# Language Garden content

Catalogue source: IANA Language Subtag Registry, https://www.iana.org/assignments/language-subtag-registry/language-subtag-registry, File-Date 2026-09-17. Includes 7,923 non-deprecated language subtags with individual/macrolanguage scopes. Collections, special values and private-use ranges are excluded. Names and alternate reference names are preserved. This catalogue is not a claim to cover every dialect, or to provide 7,923 courses.

Eight starter samples: Spanish, French, German, Italian, Portuguese, Modern Standard Arabic, Japanese and Korean. Each includes six introductory word/phrase cards with usage notes. These are introductory authored samples, not fluent-speaker-reviewed curricula. Extend and review them with fluent speakers before presenting larger structured courses.

On-device speech is enabled only when the browser reports a matching local voice. No microphone, speech scoring, cloud translation, external audio service or sign-language video lessons are included. Custom text is never inserted as HTML. Custom cards, bookmarks and progress are local browser data, not cloud accounts. Existing Kiddo Sprout arcade approval applies.
